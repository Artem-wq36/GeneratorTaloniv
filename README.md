# GeneratorTaloniv

GeneratorTaloniv — програма для створення талонів у форматі PDF з QR-кодами.

## Можливості програми

- Створення талонів у форматі PDF.
- Автоматична генерація QR-кодів.
- Збереження історії створених талонів.
- Налаштування інформації про компанію.
- Додавання логотипу компанії.
- Вибір папки для збереження готових талонів.

## Встановлення програми

1. Завантажити файл `GeneratorTaloniv_Setup.exe` із Releaes.
2. Запустити інсталятор.
3. Дотримуватися інструкцій у вікні встановлення.
4. Після завершення запустити GeneratorTaloniv через ярлик на робочому столі або в меню «Пуск».

## Запуск із вихідного коду

Для роботи з вихідним кодом потрібен встановлений Python.

1. Клонувати репозиторій:
   
   ```bash
   git clone https://github.com/Artem-wq36/GeneratorTaloniv.git
   ```

2. Перейти до папки проєкту:

   ```bash
   cd GeneratorTaloniv
   ```

3. Встановити необхідні бібліотеки:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустити програму:

   ```bash
   python main.py
   ```

## Створення EXE-файлу

Для створення виконуваного файлу використовується PyInstaller.

1. Встановити залежності з `requirements.txt`.
2. Виконати команду:

   ```bash
   pyinstaller GeneratorTaloniv.spec
   ```

3. Готовий файл `GeneratorTaloniv.exe` з'явиться в папці `dist`.

## Створення інсталятора

Для створення інсталятора використовується Inno Setup.

1. Спочатку створити EXE-файл за допомогою PyInstaller.
2. Відкрити `GeneratorTaloniv.iss` у Inno Setup Compiler.
3. Натиснути `F9` або вибрати `Build → Compile`.
4. Після успішної компіляції інсталятор з'явиться в папці `dist`.

Назва готового файлу: `GeneratorTaloniv_Setup.exe`.

## Розташування файлів програми

Під час роботи програма автоматично створює та зберігає свої дані в окремій папці Windows:

```text
%LOCALAPPDATA%\GeneratorTaloniv
```

Зазвичай повний шлях має такий вигляд:

```text
C:\Users\Ім'я_користувача\AppData\Local\GeneratorTaloniv
```

### Що міститься в цій папці?

- `settings.json` — збережені налаштування програми.
- `history.json` — історія створених талонів.
- `ticket_counter.txt` — поточний номер лічильника талонів.
- `PDF` — папка зі створеними PDF-талонами.
- `QR-коди` — папка зі згенерованими QR-кодами.
- `logos` — папка з логотипами, які використовуються програмою.

### Як відкрити папку з даними?

1. Натисніть комбінацію клавіш `Win + R`.
2. Введіть у вікні команду:

```text
%LOCALAPPDATA%\GeneratorTaloniv
```

3. Натисніть Enter.

Після цього відкриється папка з усіма даними програми.

**Примітка:** ці файли зберігаються окремо від папки встановлення програми.
